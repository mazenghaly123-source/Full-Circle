# Full Circle

Agent-facing instructions for this repository.

## Agent skills

This repo uses [Matt Pocock's engineering skills](https://github.com/mattpocock/skills),
installed as editable copies under `.claude/skills/` and tracked in `skills-lock.json`.
Update them with `npx skills update`.

### Issue tracker

Issues live in GitHub Issues on `mazenghaly123-source/Full-Circle`, with a local-markdown
`.scratch/` fallback for scratch work. See `docs/agents/issue-tracker.md`.

### Triage labels

The five canonical triage roles, using their default names: `needs-triage`, `needs-info`,
`ready-for-agent`, `ready-for-human`, `wontfix`. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: one `CONTEXT.md` and `docs/adr/` at the repo root. See `docs/agents/domain.md`.
